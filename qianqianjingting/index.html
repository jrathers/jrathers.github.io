常见问题解答

安装后无法打开播放器？

请确保您的系统已安装 Microsoft .NET Framework 2.0 或更高版本，这是千千静听运行的基础环境。

如何播放无损音乐？

千千静听原生支持 APE 和 FLAC 格式。安装后直接双击文件即可播放，无需额外解码器。

歌词显示为空白怎么办？

点击播放器界面上的“歌词”按钮，在歌词菜单中选择“搜索歌词”，系统将自动为您匹配。

支持手机端使用吗？

目前千千静听主要服务于电脑端 Windows 操作系统，暂不提供移动端应用。
